## 📋 1. 리서치 기반 의사결정 요약 (배경 지식)

질문해주신 내용에 대해 도메인 지식과 UX 리서치를 바탕으로 확정된 기준입니다.

1. **꽃 단가 및 대중적인 포장비 기준 (양재꽃시장 & 일반 플라워샵 소매가 기준)**
   * 도매 API(aT 화훼공판장 등)는 경매 단(10송이 묶음) 기준이고 인증키/CORS 제약이 있어, 소비자가 동네 꽃집에서 주문할 때 체감하는 **현실적인 소매 단가 테이블**을 AI 프롬프트와 Fallback 데이터에 내장하는 것이 가장 정확합니다.
     * **메인 꽃(Mass):** 작약/수국(`6,000~8,000원`), 장미/거베라/튤립(`3,500~5,000원`)
     * **서브/필러 꽃(Sub/Filler):** 프리지아/리시안셔스/소국(`2,500~4,000원`), 안개꽃/스타티스(`3,000~4,500원`)
     * **그린 소재(Greenery):** 유칼립투스/더스티밀러(`2,000~3,000원`)
   * **기본 포장비(Wrapping & Styling Fee):** 시중 꽃집의 대중적인 포장·공임비인 **`7,000원` 정액**을 기본 포함하여 총 예상 금액(`꽃 합계 + 7,000원`)을 현실화합니다.

2. **플로리스트 꽃 배치 기법 (Spiral & Mass-Filler-Line 구도)**
   * 실제 플로리스트의 **스파이럴 핸드타이드(Spiral Hand-tied)** 기법과 **황금 비율(매스 40~50% : 서브/필러 30~40% : 그린/라인 10~20%)** 및 **해바라기씨 나선 배치 공식(Golden Angle, $\approx 137.5^\circ$)**을 3D 좌표 계산에 적용합니다.
   * **구도 규칙:**
     * `MAIN` (매스 플라워): 다발 중앙부(반경 $r$ 최소, 높이 $y$는 중앙 볼륨 형성), 카메라/정면을 향해 약간 기울임(Tilt `0.15~0.25 rad`).
     * `SUB` (서브 플라워): 메인 꽃 주변 중간 링(Middle Ring)에 고르게 분산, 메인 꽃보다 약간 낮거나 사이사이를 메우는 각도(`0.3~0.45 rad`).
     * `FILLER` (필러 플라워): 메인과 서브 사이의 빈 공간(Interstitial Space)에 살짝 더 높게 튀어나오도록 배치해 입체감(Airy Volume) 부여.
     * `GREENERY` (그린/라인 소재): 가장 바깥쪽 외곽 링(Outer Collar)에서 다발의 아웃라인과 배경 쿠션을 잡아주도록 넓게 벌어진 각도(`0.55~0.75 rad`)로 배치.

3. **3D 컨피규레이터 UX 연구 결과 (Direct Manipulation vs 2D UI Panel)**
   * HCI/이커머스 3D 컨피규레이터 연구에 따르면:
     * **3D 직접 클릭(Direct Manipulation):** 몰입감과 심리적 소유감(Agency)이 높지만, 작은 꽃이나 뒤에 가려진 꽃(Occlusion)을 클릭하기 어렵고 무엇이 클릭 가능한지(Affordance) 알기 어렵습니다.
     * **2D 패널 선택(2D UI Panel):** 가격, 꽃말, 송이 수 조절 등 정확한 정보 탐색(Diagnosticity)과 조작 정밀도(Fitts's Law)가 월등히 높습니다.
   * **최적의 해결책 (양방향 하이브리드 연동 - Two-Way Sync):**
     * **주 조작(Primary):** 좌측 2D 카드 리스트에서 꽃 교체 및 `+ / -` 송이 수 조절을 수행.
     * **보조 조작(Secondary):** 3D 캔버스에서 꽃 위에 마우스를 올리면 해당 슬롯 전체가 부드럽게 하이라이트(Emissive Glow)되며 `[꽃 이름 + 꽃말]` 툴팁이 뜨고, 클릭 시 좌측 2D 패널의 해당 슬롯 교체 창이 자동으로 열리고 스크롤됩니다. 반대로 좌측 2D 패널에서 슬롯을 클릭해도 3D 캔버스의 해당 꽃들이 하이라이트됩니다.

4. **실사 이미지 지연/실패 시 업계 표준 UX (Graceful Degradation)**
   * 실사 생성 API가 지연되거나 실패하더라도 유저 플로우가 절대 막히지 않도록, **Three.js 3D 캔버스의 고화질 캡처본(`gl.domElement.toDataURL('image/png')` - 정면 뷰 & 항공샷)**을 기본 레퍼런스 이미지로 즉시 사용하여 플로리스트 주문 가이드를 발급합니다. 실사 이미지가 생성된 경우에만 나란히 추가 표시합니다.

## 🚀 2. AI Studio / 프로토타입 수정 요청 프롬프트 (`[프롬프트 복사 영역]`)

아래 코드 블록 전체를 복사해서 프롬프트 창에 입력해 주세요.

```markdown
현재 구현된 **Darte Flores (다르테 플로레스)** 프로토타입에 아래 8가지 상세 기획 및 UX/UI 고도화 요구사항을 반영하여 코드를 수정해 줘. 기존 디자인 컬러 시스템(`#F5F4ED`, `#E7DBC1`, `#BF6C8B`, `#CCDFAA`, `#F0B659`, `#2D2A26`)과 TypeScript 타입 안전성은 그대로 유지해야 해.

### 1. 현실적인 꽃 소매 단가 기준 및 대중적인 기본 포장비(7,000원) 반영
- **단가 현실화 (`services/geminiService.ts` 프롬프트 및 Fallback 데이터):**
  - 한국 일반 플라워샵 소매가 기준으로 송이당 단가(`pricePerStem`)를 산정하도록 Gemini 프롬프트와 기본 데이터를 업데이트해 줘.
  - 기준가: 메인 꽃(작약/수국 6,000~8,000원, 장미/튤립/거베라 3,500~5,000원), 서브/필러 꽃(프리지아/리시안셔스/안개꽃 2,500~4,500원), 그린 소재(유칼립투스 2,000~3,000원).
- **기본 포장비 상수 도입:**
  - `WRAPPING_FEE = 7000` (대중적인 포장·스타일링 공임비 7,000원) 상수를 정의해 줘.
  - 총 예상 금액(`estimatedTotalCost`)은 항상 `모든 슬롯의 (stemCount * pricePerStem) 합계 + WRAPPING_FEE(7,000원)`으로 실시간 계산되어야 하며, UI의 예산 게이지 옆과 플로리스트 주문서에 `(기본 포장·스타일링비 7,000원 포함)` 문구를 명시해 줘.

### 2. 슬롯 꽃 교체(Swap), 송이 수(`+ / -`) 직접 조절, 예산 초과 경고(Warning) UX
- **권장 송이 수 적용:** 사용자가 주변 꽃 슬롯을 다른 후보 꽃(`swapCandidates`)으로 교체할 때, 교체되는 후보 객체에 정의된 권장 `stemCount`와 `pricePerStem`으로 함께 업데이트해 줘.
- **송이 수 직접 조절 (`+ / -` 버튼):**
  - Step 4의 각 꽃 슬롯 카드(`MAIN`, `SUB`, `FILLER`, `GREENERY` 모두 포함)에 사용자가 직접 송이 수(`stemCount`)를 조절할 수 있는 `-` / `+` 버튼을 추가해 줘 (최소 1송이 ~ 최대 15송이).
  - 송이 수가 변경되면 즉시 3D 뷰어의 꽃 개수와 하단 총 예상 금액이 실시간으로 반영되어야 해.
- **예산 초과 시 경고(Non-blocking Warning) 처리:**
  - 꽃 교체나 송이 수 증가로 인해 총 예상 금액이 Step 1에서 설정한 예산을 초과하더라도 **선택을 막지 말고 허용**해 줘.
  - 대신 하단 예산 게이지 바의 색상을 기존 `#CCDFAA`(안정권)에서 경고색인 **`#F6A93A` (Marigold Orange)**로 변경하고, `⚠️ 설정 예산보다 +N,000원 초과되었습니다 (송이 수를 조절하거나 다른 꽃으로 변경해 보세요)`라는 부드러운 안내 배지를 표시해 줘.

### 3. 플로리스트 '스파이럴 핸드타이드(Spiral Hand-tied)' 기법 기반 3D 꽃 배치 알고리즘 (`BouquetCanvas3D.tsx`)
- 꽃들이 인위적인 격자나 단순 원형으로 겹쳐 보이지 않도록, 실제 플로리스트의 **매스-필러-라인(Mass-Filler-Line) 계층 구도**와 **황금각 나선(Golden Angle Spiral, `137.5도 = 2.39996 rad`)** 공식을 결합해 자연스러운 돔(Dome) 형태의 부케로 배치해 줘:
  1. **`MAIN` (매스 플라워 - 시선 중심):** 다발 중심부(`radius: 0.0 ~ 0.35`), 가장 돋보이는 중앙 높이, 줄기 기울기(`tilt: 0.08 ~ 0.22 rad`)로 배치하여 시각적 무게 중심을 잡는다.
  2. **`SUB` (서브 플라워 - 볼륨 확장):** 메인 꽃 주변 중간 링(`radius: 0.35 ~ 0.65`), 황금각 나선으로 메인 꽃들과 겹치지 않게 사이사이에 배치하고, 바깥쪽으로 자연스럽게 기울인다(`tilt: 0.25 ~ 0.42 rad`).
  3. **`FILLER` (필러 플라워 - 공간 메우기 & 리듬감):** 메인과 서브 사이의 빈 공간(`radius: 0.25 ~ 0.70`)에 배치하되, 높이를 살짝 더 높게(`+0.15 ~ +0.25`) 띄워 잔꽃들이 꽃다발 위로 폭죽처럼 은은하게 올라오는 입체감을 연출한다.
  4. **`GREENERY` (그린/라인 소재 - 아웃라인 & 베이스 쿠션):** 가장 바깥쪽 외곽 링(`radius: 0.65 ~ 0.95`)에 배치하고 바깥으로 넓게 펼쳐진 각도(`tilt: 0.48 ~ 0.68 rad`)를 적용해 꽃다발 전체를 감싸는 자연스러운 잎사귀 프레임을 만든다.
  5. 모든 꽃 줄기(Stem)의 하단 끝점은 포장지 내부의 한 지점(**바인딩 포인트, Binding Point**)을 향해 모이도록 회전축을 계산해 실제 스파이럴 핸드타이드 형태를 구현해 줘.

### 4. 2D 패널 & 3D 뷰어 양방향 하이브리드 인터랙션 (Two-Way Sync)
- UX 연구의 모범 사례인 **2D UI 패널(주 조작) + 3D 직접 조작(보조 탐색) 양방향 동기화**를 구현해 줘:
  - **3D → 2D 연동:** 3D 캔버스에서 특정 꽃 메쉬에 마우스를 호버하면 같은 슬롯(`slotId`)의 꽃들이 살짝 밝아지며(`[꽃 이름 · 꽃말]` 플로팅 툴팁 표시), 클릭하면 좌측 2D 패널에서 해당 슬롯이 선택 상태로 활성화되고 교체 후보(`swapCandidates`) 영역으로 부드럽게 스크롤(`scrollIntoView`)되게 해 줘.
  - **2D → 3D 연동:** 좌측 2D 패널에서 특정 꽃 슬롯에 마우스를 올리거나 클릭하면, 3D 캔버스 내 해당 슬롯의 꽃들에 하이라이트 효과(Emissive 강조 또는 살짝 커지는 스케일 애니메이션)를 주어 어느 위치의 꽃인지 직관적으로 알 수 있게 해 줘.

### 5. 무관한 사진 업로드 검증 및 안내 (Multimodal Validation)
- `OccasionAnalysisResponse` 인터페이스에 다음 필드를 추가해 줘:
  ```typescript
  isImageRelevant?: boolean; // 업로드한 사진이 인물/의상/장소/분위기 파악에 적합한지 여부
  imageValidationMessage?: string; // 무관한 사진일 때 사용자에게 보여줄 친절한 안내 문구
  ```
- 사용자가 업로드한 이미지가 꽃다발 분위기 추천과 전혀 무관한 사진(예: 코드 스크린샷, 영수증, 문서, 완전한 단색 검은 화면 등)일 경우, Gemini가 `isImageRelevant: false`를 반환하도록 하고, UI에 **`"업로드하신 사진에서 분위기 요소를 찾기 어려워, 선택하신 기념일('[기념일명]')을 기준으로 어울리는 꽃을 추천해 드렸어요."`**라는 안내 배너를 띄운 뒤 기념일 텍스트 기반으로 정상 진행되게 해 줘.

### 6. 실사 이미지 수동 재생성 유도 및 버전 히스토리 비교 (API 호출 절약 & 이전 버전 복원)
- 사용자가 3D 뷰어에서 꽃 종류, 송이 수, 포장지/리본 색상을 변경할 때마다 자동으로 실사 이미지 생성 API를 호출하지 마.
- **Dirty State 감지:** 이미 실사 이미지를 한 번 생성한 상태에서 3D 구성이 변경되면, 실사 프리뷰 영역 상단에 **`"🔄 3D 꽃다발 구성이 변경되었습니다. 변경사항을 반영하려면 [실사 이미지 다시 생성하기]를 눌러주세요."`** 안내 배너와 버튼을 표시해 줘.
- **생성 히스토리(History) 보관 및 불러오기:**
  - 생성된 실사 이미지들을 버리지 않고 배열(`generatedHistory: Array<{ id: string, timestamp: string, imageUrl: string, bouquetSnapshot: BouquetStyle }>`)로 보관해 줘.
  - 실사 프리뷰 하단에 **이전 생성 버전 썸네일 리스트**를 보여주고, 사용자가 이전 버전을 클릭하면 `"이전 버전이 더 마음에 드시나요?"`와 함께 해당 실사 이미지 및 당시의 3D 꽃다발 구성으로 즉시 되돌릴 수 있는 `[이 버전으로 복원]` 기능을 제공해 줘.

### 7. 단계 이동 시 히스토리/상태 보존 (`localStorage` & State Preservation)
- 사용자가 Step 4에서 작업하다가 Step 1, Step 2, Step 3으로 되돌아가더라도 기존에 추천받은 결과나 커스텀하던 상태가 바로 증발하지 않도록 React State와 `localStorage`에 단계별 상태를 보존해 줘.
- 만약 이전 스텝에서 기념일이나 메인 꽃을 **새로 변경하여 다시 생성**할 때만 기존 세션을 업데이트하되, 상단에 **최근 작업한 꽃다발 히스토리 드롭다운(최대 5개 저장)**을 제공해 언제든 이전에 만들던 꽃다발을 다시 불러올 수 있게 해 줘.

### 8. 플로리스트 소통 가이드 시트(`FloristGuideModal.tsx`) 고도화 및 실사 실패 Fallback
- **실사 이미지 미생성/실패 시 Fallback (Graceful Degradation):**
  - 사용자가 실사 이미지를 아직 생성하지 않았거나 API 지연/오류로 실패한 상태에서도 `[📋 플로리스트 주문 가이드 발급]` 버튼을 누르면 모달이 정상적으로 열려야 해.
